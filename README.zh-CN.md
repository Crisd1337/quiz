# Canvas 复习站 · Year 10

**中文** · [English](README.md)

用 Year 10 课程材料做的一个复习站：**16 科 · 428 题**，简答题会按评分标准自动判分，错题按遗忘曲线回炉，另有一套轻量的激励系统。纯静态 HTML，没有框架、没有构建服务器、不用登录。

## 里面有什么

- **428 道题**：266 道选择、162 道简答，覆盖 16 科（英语、科学、数学 P、数学 5.3、历史、地理、PDHPE，以及非年考选修）。
- **简答题是真判分**：每道题带一份评分标准，各条得分点之和必须等于该题总分。提交后浏览器把答案发给 Cloudflare Worker，由模型逐条给分并说明理由；如果答案与参考答案的用词覆盖率足够高，会先走确定性满分规则（不调模型、不花钱）。
- **全站双语**：默认英文，所有界面、标签和解析都有中文版。
- **错题本 + 遗忘曲线**：答错进队列，第 1 / 3 / 7 天回炉，连对两次「毕业」。
- **激励系统**：按得分比例给经验、每科掌握度、每日任务、金币商店、徽章，以及可选的好友榜。
- **能离线用**：所有进度存在 `localStorage`；除 AI 判分和排行榜外，断网也能做题。

## 怎么实现的

```
浏览器（静态 HTML，进度在 localStorage）
   │
   ├── POST /grade  → Cloudflare Worker → Gemini / Groq / Workers AI
   └── POST /score  → Cloudflare Worker → D1（排行榜）
```

- 整站由一个 Python 脚本生成：题目数据（`questions/*.json`）先校验，再把每页写成自包含的单个 HTML（CSS/JS 内联），构建时注入统一的设计变量和主题代码。
- Worker 保存 API key（绝不下发到浏览器），按 IP 做每日配额，并且只接受来自本站域名的请求。
- 没有账号、没有 cookie、没有统计脚本。

## 隐私

- 进度、经验、金币、错题本：**只存在你的浏览器里**。清缓存就全没了，换设备请用「导出备份」。
- 排行榜：你填的昵称 + 成绩，存在 Worker 的 D1 里。**是自己上报的，没有服务端校验**，当个乐子看就行。
- 判分：答案只在那一次请求里发给模型服务商。

## 已知局限

- AI 判分是学习工具，不是考试阅卷。它对「堆关键词」故意很严，但拿不准的答案还是自己核一下。
- 排行榜数据是客户端上报的，打开开发者工具就能改，没有防作弊。
- 题库覆盖的是原始资料里出现的考点，不是完整考纲。
